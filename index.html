API & System Settings

CareerCompass connects automatically to the local Node.js backend or Vercel serverless function. You can also supply a personal Gemini API key if running without a server.

🔥

Connect Firebase

Connect your Firebase project to enable Google Sign-In and automatically back up your saved careers, roadmaps, quiz results, and study checklists to Firestore.

💡 Tip: In your Firebase Console, ensure Google is enabled under Authentication → Sign-in method, and Firestore Database is created in test/production mode.
